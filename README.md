# Heaper Releases

App downloads live in this repository’s [upstream releases](https://github.com/JanLunge/heaper-releases/releases). Docker images are at [ghcr.io/janlunge/heaper](https://github.com/users/JanLunge/packages/container/package/heaper).

## Start here

- [Self-host with Docker](docs/self-hosting.md) — complete all-in-one compose setup, operations, backups, and desktop connection on port `3010`
- [Desktop app](docs/desktop.md) — Linux AppImage setup, Windows/macOS artifact choices, login flow, and self-hosted server connection

## Scope and integrations

This repository only documents what is verified here:

- the desktop release artifacts published in [JanLunge/heaper-releases](https://github.com/JanLunge/heaper-releases/releases)
- the bundled self-hosting setup in [`docker-compose.yml`](docker-compose.yml)
- the desktop-to-self-hosted-server connection described in the docs above

For broader product documentation, use the official docs: [self-hosting](https://docs.heaper.de/docs/self-hosting), [download](https://docs.heaper.de/download).
